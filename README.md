# University Course Enrollment Application

A Ruby on Rails learning project for a university-style course enrolment workflow. The routes include course listings, student resources, login/logout and a student course-enrolment action.

## Features represented in the application

- Course listing as the home page
- Course creation route
- Student resource management
- Login and logout routes
- Course-enrolment action connecting students with courses
- About page

## Technology

- Ruby 2.7.7
- Ruby on Rails 5.2
- SQLite
- Active Record
- MaterializeCSS
- Material Icons
- jQuery
- BCrypt
- Puma

## Run locally

1. Install Ruby 2.7.7 and Bundler.
2. Clone the repository and enter the project directory.
3. Install dependencies: `bundle install`.
4. Prepare the database: `bin/rails db:create db:migrate`.
5. Start Rails: `bin/rails server`.

Open the local Rails URL shown in the terminal.

## Learning focus

Rails MVC, relational data modelling, resource routing, student/course workflows, authentication foundations and responsive UI styling with MaterializeCSS.

Consult the source code for details of the enrolment implementation.
